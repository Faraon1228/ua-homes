## Ukrainian (uk-UA)

### Short description (<=80)
Пошук нерухомості в Україні: оголошення, фільтри, обране.

### Full description
UA-Dim — це мобільний доступ до маркетплейсу нерухомості в Україні.

Що ви можете робити в застосунку:
- шукати квартири, будинки та земельні ділянки за фільтрами;
- переглядати фото, описи, ціни та деталі оголошень;
- відкривати картки об’єктів за прямими посиланнями;
- зберігати обране та налаштування пошуку;
- для продавців — керувати оголошеннями у веб-кабінеті UA-Dim.

Технічні особливості:
- офіційний мобільний клієнт UA-Dim з завантаженням актуального продакшн-інтерфейсу;
- підтримка push-сповіщень за наявності дозволу;
- стабільна робота через HTTPS-з’єднання.

Важливо:
- UA-Dim є платформою для розміщення оголошень і не є стороною угод між користувачами;
- сервіс не призначений для осіб молодше 18 років.

## English (en-US)

### Short description (<=80)
Find real estate in Ukraine: listings, filters, and saved favorites.

### Full description
UA-Dim is a mobile entry point to the UA-Dim real estate marketplace in Ukraine.

What you can do:
- search apartments, houses, and land listings with practical filters;
- review listing photos, descriptions, prices, and details;
- open listing cards from direct links;
- keep favorites and search preferences;
- for sellers, manage listings in the UA-Dim web workspace.

Technical highlights:
- official UA-Dim mobile client connected to the live production experience;
- push notification support when permission is granted;
- secure HTTPS data transport.

Important:
- UA-Dim is a listing platform and not a party to transactions between users;
- the service is not intended for users under 18.
