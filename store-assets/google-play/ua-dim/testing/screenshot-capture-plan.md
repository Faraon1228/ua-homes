# Screenshot capture plan (1080x1920, authentic app-only)

Use a real device or emulator with UA-Dim build `1.0.1 (7)`. Capture only genuine runtime screens in portrait at **1080×1920**.

## Required scene set

1. **Home / search landing**
   - Show UA-Dim app header and first visible listings.
2. **Filtered results**
   - Apply practical filters (price/rooms/location) and capture updated list.
3. **Listing details page**
   - Open one listing and show gallery + price + key attributes.
4. **Favorites saved state**
   - Save at least one listing and capture favorites/selected indicator.
5. **Seller listing management (if seller account available)**
   - Show seller workflow screen proving listing-management capability.
6. **Deep-link opened listing**
   - Open `https://ua-dim.com/listing/{id}` from outside app and capture in-app result.

## Capture quality controls

- Remove personal data from test accounts before capture.
- Use consistent locale per store language set.
- Do not overlay fake badges, rankings, or claims on screenshots.
- Re-check each file resolution before upload (exact 1080×1920).
