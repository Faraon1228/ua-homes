# Tester instructions (internal/closed testing)

1. Install build `1.0.1 (7)` from the assigned Play test track.
2. Launch UA-Dim and allow notifications only if you are testing push behavior.
3. Verify home/load flow opens UA-Dim production content.
4. Open at least one deep link to `https://ua-dim.com/listing/{id}` and confirm in-app navigation.
5. Sign in with a test account and confirm session is restored after app restart.
6. Browse listings, apply filters, and save at least one favorite.
7. If seller access is available, open listing management and test media upload flow.
8. Turn connectivity off/on and confirm the app recovers without a forced reinstall.
9. Report issues with:
   - device model + Android version,
   - exact time (UTC),
   - reproduction steps,
   - expected vs actual behavior,
   - screenshot/screen recording if possible.
